Universal API Integration Guide

Chatterbox provides a standard, robust REST API with observable lifecycle transitions and forensic WAV audio verification.

1. Python Client Adapter:

from chatterbox.client import OrqevynSpeechClient

client = OrqevynSpeechClient(base_url="http://127.0.0.1:8000")

result = client.speak_text(
    text="Welcome to the autonomous neural speech engine.",
    language="en",
    voice="en_female",
    options={"exaggeration": 0.5, "wait": True}
)

print(f"Verified Audio File: {result.audio_path}")
print(f"Duration: {result.duration_seconds}s | Sample Rate: {result.sample_rate}Hz")

2. cURL / Shell:

curl -X POST "http://127.0.0.1:8000/v1/speech" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Hello world from Chatterbox Speech Engine.",
    "language": "en",
    "voice": "en_female",
    "options": {"wait": true}
  }'

3. JavaScript / TypeScript / Node.js:

const response = await fetch("http://127.0.0.1:8000/v1/speech", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    text: "Welcome to the speech studio.",
    language: "en",
    voice: "en_female",
    options: { wait: true }
  })
});
const job = await response.json();
console.log("Audio URL:", `http://127.0.0.1:8000${job.artifact.audio_url}`);

4. C# (.NET 8 - Orqevyn Native Integration):

using Orqevyn.Core.Speech;

var client = new OrqevynSpeechClient(new HttpClient { BaseAddress = new Uri("http://127.0.0.1:8000") });
var result = await client.SpeakTextAsync(
    text: "Welcome to Orqevyn speech engine.",
    language: "en",
    voice: "en_female"
);
Console.WriteLine($"Audio verified and ready at: {result.AudioPath}");
